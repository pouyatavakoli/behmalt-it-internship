---
title: Glossary
description: Glossary of terms used throughout this documentation.
---

| Term | Definition |
|---|---|
| **AD** | Active Directory — Microsoft's directory service for centrally managing users, computers, and policy in a domain. |
| **CA** | Certificate Authority — issues and manages digital certificates. |
| **CIDR** | Classless Inter-Domain Routing notation (e.g., `/24`) specifying subnet size. |
| **DHCP** | Dynamic Host Configuration Protocol — automatically assigns IP addresses to devices. |
| **DNS** | Domain Name System — resolves hostnames to IP addresses. |
| **FTTH** | Fiber to the Home — fiber optic cabling run directly to the end-user premises. |
| **KMS** | Key Management Service — centralized Windows license activation. |
| **KVM** | Keyboard, Video, Mouse switch — allows shared control of multiple servers. |
| **NAT** | Network Address Translation — translates private to public IP addresses (src-nat: outbound, dst-nat: inbound). |
| **NTP** | Network Time Protocol — synchronizes time across systems. |
| **PoE** | Power over Ethernet — delivers electrical power over a data cable. |
| **RouterOS** | MikroTik's router operating system. |
| **UTM** | Unified Threat Management — a firewall combined with additional security features. |
| **VLAN** | Virtual LAN — logically segments a physical network at Layer 2. |
| **VoIP** | Voice over IP — carries voice traffic over an IP network. |
| **Winbox** | MikroTik's dedicated RouterOS configuration application. |
