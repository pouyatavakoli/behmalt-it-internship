title: Tools
description: Tools used or referenced throughout this documentation.
--------------------------------------------------------------------

* **Winbox** — Configuration and management tool for MikroTik RouterOS
* **RouterOS Web Interface** — Browser-based interface for managing and configuring RouterOS over HTTP/HTTPS
* **Fluke Tester** — Professional tool for testing and certifying network cabling
* **Wire-Mapping Tester** — Basic tool for checking cable continuity and wire mapping
* **Punch-Down Tool** — Used to terminate cable wires in keystone jacks and patch panels
* **Fiber Splicing and Termination Tools** — Used for preparing, splicing, and terminating fiber-optic cables
* **Server Manager** — Windows Server management console for managing roles, services, and server configuration
* **Active Directory Users and Computers (ADUC)** — Management console for users, groups, and other Active Directory objects
* **Issabel** — VoIP and PBX platform used at BehMalt

For more details, see [Hardware](/behmalt-it-internship/it-environment/hardware/) and [Network](/behmalt-it-internship/it-environment/network/).
