---
title: واژه‌نامه
description: واژه‌نامه اصطلاحات مورد استفاده در سراسر این مستندات.
---

| اصطلاح | تعریف |
|---|---|
| **AD** | Active Directory — سرویس directory متعلق به مایکروسافت برای مدیریت متمرکز کاربران، کامپیوترها و policy در یک domain. |
| **CA** | Certificate Authority — صادر و مدیریت گواهی‌های دیجیتال. |
| **CIDR** | نماد Classless Inter-Domain Routing (مثلاً `/24`) که اندازه subnet را مشخص می‌کند. |
| **DHCP** | Dynamic Host Configuration Protocol — به‌طور خودکار آدرس‌های IP را به دستگاه‌ها اختصاص می‌دهد. |
| **DNS** | Domain Name System — نام‌های host را به آدرس‌های IP تفکیک می‌کند. |
| **FTTH** | Fiber to the Home — کابل‌کشی فیبر نوری که مستقیماً به محل کاربر نهایی کشیده می‌شود. |
| **KMS** | Key Management Service — فعال‌سازی لایسنس متمرکز ویندوز. |
| **KVM** | سوییچ Keyboard, Video, Mouse — امکان کنترل مشترک چندین سرور را فراهم می‌کند. |
| **NAT** | Network Address Translation — آدرس‌های IP خصوصی را به عمومی ترجمه می‌کند (src-nat: خروجی، dst-nat: ورودی). |
| **NTP** | Network Time Protocol — زمان را در سراسر سیستم‌ها همگام می‌کند. |
| **PoE** | Power over Ethernet — برق را از طریق یک کابل داده منتقل می‌کند. |
| **RouterOS** | سیستم‌عامل روتر متعلق به MikroTik. |
| **UTM** | Unified Threat Management — یک firewall ترکیب‌شده با ویژگی‌های امنیتی اضافی. |
| **VLAN** | Virtual LAN — یک شبکه فیزیکی را به‌صورت منطقی در لایه ۲ تقسیم‌بندی می‌کند. |
| **VoIP** | Voice over IP — ترافیک صوتی را از طریق یک شبکه IP منتقل می‌کند. |
| **Winbox** | ابزار اختصاصی پیکربندی RouterOS متعلق به MikroTik. |
