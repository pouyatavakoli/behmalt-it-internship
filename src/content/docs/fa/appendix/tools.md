---
title: ابزارها
description: ابزارهای مورد استفاده یا ارجاع‌شده در سراسر این مستندات.
---

* **Winbox** — ابزار پیکربندی و مدیریت RouterOS برای تجهیزات MikroTik
* **رابط وب RouterOS** — رابط تحت وب برای مدیریت و پیکربندی RouterOS از طریق HTTP/HTTPS
* **تستر Fluke** — ابزار حرفه‌ای تست و صدور گواهی برای کابل‌کشی شبکه
* **تستر Wire-Mapping** — ابزار ساده برای بررسی تداوم و ترتیب سیم‌های کابل شبکه
* **ابزار پانچ (Punch-Down Tool)** — برای ترمینیشن رشته‌های کابل در Keystone Jack و Patch Panel
* **ابزارهای فیوژن و ترمینیشن فیبر نوری** — برای آماده‌سازی، اتصال و ترمینیشن کابل‌های فیبر نوری
* **Server Manager** — کنسول مدیریت نقش‌ها، سرویس‌ها و تنظیمات Windows Server
* **Active Directory Users and Computers (ADUC)** — کنسول مدیریت کاربران، گروه‌ها و اشیای Active Directory
* **Issabel** — پلتفرم VoIP و PBX مورد استفاده در BehMalt

 برای جزئیات بیشتر، به [سخت‌افزار](/behmalt-it-internship/fa/it-environment/hardware/) و [شبکه](/behmalt-it-internship/fa/it-environment/network/) مراجعه کنید.
