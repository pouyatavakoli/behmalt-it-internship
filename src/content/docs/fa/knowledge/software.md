## نمای کلی

این صفحه نرم‌افزار و پلتفرم‌های عمومی مواجه‌شده در طول کارآموزی را پوشش می‌دهد: ابزارهای مدیریتی Windows Server، ابزارهای مدیریت MikroTik/VoIP، Microsoft Access و پلتفرم پیام‌رسانی SMS.ir. سیستم‌های خاص کسب‌وکار (ERP، CRM و غیره) در [سیستم‌های کسب‌وکار](/fa/business-systems/overview/) پوشش داده شده‌اند.

## ابزارهای Windows Server و شبکه

- **Windows Server** و ابزارهای مدیریتی آن (Server Manager، Active Directory Users and Computers) — به [سرورها و اتاق سرور ← Windows Server](/fa/it-environment/servers-server-room/) مراجعه کنید.
- **Winbox** و رابط وب RouterOS، مورد استفاده برای مدیریت دستگاه‌های MikroTik — به [شبکه ← MikroTik](/fa/it-environment/network/) مراجعه کنید.
- **Issabel**، پلتفرمی که VoIP و مسیریابی تماس contact center روی آن پیکربندی شد — به [شبکه ← مدیریت Issabel Contact Center / PBX](/fa/it-environment/network/) مراجعه کنید.
- **Kerio Control**، مورد استفاده به‌عنوان firewall/UTM — به [امنیت ← Firewall و UTM](/fa/it-environment/security/) مراجعه کنید.
- **vSphere / vCenter / ESXi**، مورد استفاده برای مجازی‌سازی سرور — به [سرورها و اتاق سرور ← سرورهای فیزیکی و مجازی‌سازی](/fa/it-environment/servers-server-room/) مراجعه کنید.

## Microsoft Access

### مفاهیم

**Microsoft Access** یک سیستم مدیریت پایگاه داده رابطه‌ای (RDBMS) دسکتاپ است که همراه با Microsoft Office عرضه می‌شود. این نرم‌افزار یک موتور پایگاه داده (مبتنی بر Access Database Engine / Jet) را با ابزارهای داخلی برای ساخت فرم‌ها، کوئری‌ها و گزارش‌ها ترکیب می‌کند و امکان ساخت برنامه‌های داده‌محور کوچک تا متوسط را بدون نیاز به سرور پایگاه داده جداگانه یا نوشتن یک برنامه کامل از صفر فراهم می‌کند.

کاربردهای رایج Microsoft Access شامل:

- **ردیابی داده کسب‌وکارهای کوچک** — مثلاً لیست‌های موجودی، رکوردهای مخاطب/مشتری، ردیابی سفارش ساده — برای سازمان‌هایی که خیلی کوچک‌تر از آن هستند که یک استقرار کامل ERP/CRM را توجیه کنند.
- **نمونه‌سازی سریع برنامه‌های ورود داده** — ساخت سریع یک برنامه کاربردی مبتنی بر فرم با استفاده از طراح فرم داخلی Access، پیش از (در صورت نیاز) انتقال مدل داده به یک پلتفرم پایگاه داده قوی‌تر.
- **پایگاه‌های داده بخشی یا شخصی** — توسط تیم‌های منفرد برای ردیابی داده مرتبط با گردش‌کار خودشان (مثلاً یک لاگ نگهداری و تعمیرات، یک چک‌لیست دارایی) بدون نیاز به تأمین یک پایگاه داده سروری اختصاصی توسط IT استفاده می‌شود.
- **گزارش‌گیری** — تولید گزارش‌های چاپی/قابل‌خروجی و قالب‌بندی‌شده مستقیماً از داده ذخیره‌شده با استفاده از طراح گزارش داخلی Access.
- **Front-end برای پایگاه‌های داده بزرگ‌تر** — Access همچنین می‌تواند به‌عنوان یک front-end (لایه فرم‌ها/گزارش‌ها) متصل به یک موتور پایگاه داده back-end مانند SQL Server عمل کند و به کاربران اجازه دهد از طریق یک رابط ساده‌تر مبتنی بر Access با یک پایگاه داده مرکزی بزرگ‌تر تعامل داشته باشند.

### در به‌مالت

Microsoft Access در طول کارآموزی به‌عنوان ابزاری برای کار با داده معرفی شد — ساخت و کوئری‌گیری پایگاه‌های داده ساده مستقیماً از درون مجموعه Microsoft Office. برنامه‌های خاص مبتنی بر Access مورد استفاده در به‌مالت در یادداشت‌ها ذکر نشده‌اند — `[نامشخص]`.

## SMS.ir (پنل پیامک)

### مفاهیم

**SMS.ir** یک سرویس/پنل SMS gateway است که به سازمان‌ها اجازه می‌دهد پیامک‌های انبوه یا فردی را به‌صورت برنامه‌نویسی‌شده یا از طریق یک پنل وب برای کاربران ارسال کنند. چنین پلتفرم‌هایی معمولاً چندین **خط ارسال** ارائه می‌دهند که هرکدام قوانین و کاربردهای متفاوتی دارند:

- **خطوط خدماتی (Service/Transactional)** — برای پیام‌های عملیاتی/خدماتی استفاده می‌شوند (مثلاً تأیید سفارش، یادآوری قرار ملاقات، کدهای تأیید). این پیام‌ها معمولاً حتی به شماره‌هایی که تبلیغات را غیرفعال کرده‌اند نیز تحویل داده می‌شوند، اما ارسال **محتوای تبلیغاتی** از طریق خط خدماتی برخلاف policy استفاده ارائه‌دهنده است.
- **خطوط تبلیغاتی (Advertising/Promotional)** — به‌طور خاص برای محتوای بازاریابی استفاده می‌شوند، و مشمول opt-out/مسدودسازی توسط دریافت‌کنندگانی هستند که مایل به دریافت تبلیغات نیستند.

SMS.ir همچنین از **ارسال هدفمند بر اساس منطقه/محدوده جغرافیایی** پشتیبانی می‌کند، که امکان ارسال پیام به دریافت‌کنندگان درون یک منطقه جغرافیایی خاص را فراهم می‌کند — مفید برای کمپین‌های تبلیغاتی محلی (مثلاً تبلیغ افتتاح یک فروشگاه یا پیشنهاد محلی به گیرندگان نزدیک) بدون نیاز به لیست مخاطبین از پیش موجود برای آن منطقه.

### در به‌مالت

SMS.ir به‌عنوان پلتفرمی برای ارسال پیامک به کاربران معرفی شد، با تمایز بین خطوط خدماتی (پیام‌های عملیاتی، غیرمجاز برای تبلیغات) و خطوط تبلیغاتی (محتوای بازاریابی، قابل‌مسدودشدن توسط کاربران)، همچنین قابلیت ارسال هدفمند بر اساس منطقه برای تبلیغات محلی. کاربردهای خاص به‌مالت (مثلاً کدام خط برای کدام فرآیند کسب‌وکار استفاده می‌شود) در یادداشت‌ها ذکر نشده است — `[نامشخص]`.
