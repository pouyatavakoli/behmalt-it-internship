---
title: درس‌های عملیاتی
description: درس‌های عملیاتی آموخته‌شده در طول کارآموزی.
---

- همیشه پیش از اعمال تغییرات سخت‌سازی پورت، یک پورت روتر را برای دسترسی اضطراری بدون پیکربندی باقی بگذارید — یک تدبیر ایمنی در برابر قفل شدن اتفاقی خارج از دسترسی.
- حساب پیش‌فرض Administrator را در Windows Server / Active Directory غیرفعال کنید و به‌جای آن از یک حساب مدیریتی نام‌گذاری‌شده اختصاصی استفاده کنید، تا خطر هدف قرار گرفتن یک حساب شناخته‌شده کاهش یابد.
- پورت‌های مدیریتی پیش‌فرض را تغییر دهید و پورت‌ها/سرویس‌های استفاده‌نشده را روی تجهیزات شبکه غیرفعال کنید به‌عنوان یک گام سخت‌سازی پایه.
- برای محیط‌های بزرگ‌تر، از سرویس‌های متمرکز (سرورهای توزیع به‌روزرسانی، KMS، اشتراک‌گذاری پرینتر/فایل مبتنی بر AD) برای کاهش سربار مدیریتی استفاده کنید.
- کنترل محیطی (دما، رطوبت) و کاهش خطر حریق دغدغه‌های عملیاتی مداوم و ضروری برای یک اتاق سرور هستند، نه وظایف راه‌اندازی یک‌باره.
- یک شبکه مبتنی بر domain (به‌جای workgroup) اجازه می‌دهد یک هویت کاربری واحد به‌طور مداوم در سراسر سیستم‌ها — از جمله ارجاع مستقیم در قوانین دسترسی firewall — استفاده مجدد شود، به‌جای تکرار مدیریت دسترسی برای هر سیستم.
- محدوده‌های استثنای DHCP باید برای دستگاه‌های زیرساختی (سرورها، پرینترها) تعریف شوند تا هرگز به‌طور پویا به دستگاه‌های کلاینت معمولی اختصاص نیابند.
- iLO (یا معادل مدیریت out-of-band) باید با یک آدرس IP قابل‌دسترس به‌عنوان یکی از اولین گام‌ها هنگام راه‌اندازی یک سرور فیزیکی جدید پیکربندی شود، زیرا دسترسی مستقل از سیستم‌عامل اصلی سرور فراهم می‌کند.
