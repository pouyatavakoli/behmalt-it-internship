This section provides a non-chronological summary of the internship activities. Detailed technical content has been moved into the **IT Environment**, **Business Systems**, and **Knowledge** sections; this page only summarizes what was covered and worked on.

- Introduction to the IT department's role and structure within the company
- Network infrastructure: topology, passive cabling, structured cabling standards, fiber optics
- Network security concepts across layers (firewall/UTM, router, switch)
- VoIP infrastructure and configuration
- MikroTik router configuration and administration
- Windows Server administration, Active Directory, and related services
- Physical security and server room standards
- Company documentation practices
