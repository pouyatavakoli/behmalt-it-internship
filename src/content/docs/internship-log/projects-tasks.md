## Proposal: QR Code-Based Pool Access System

During the internship, an opportunity to improve the employee pool access process was identified, leading to a proposal for a **QR Code-based access system**. The proposal is currently **pending CEO review and approval**.

### Identified Problem

Employee access to the pool is currently managed using **printed physical access cards**. This approach requires manual handling and maintenance in daily use and can be prone to errors.

### Proposed Solution

The proposed solution is to replace printed cards with a **QR Code-based access system** using the following workflow:

1. **An administrator manages the employee account and assigns a pool session allowance.**
2. **The employee presents their QR Code, for example from a mobile phone, when visiting the pool.**
3. **The system scans the QR Code, verifies the employee's remaining allowance, and grants or denies access accordingly. A successful entry automatically deducts one session from the allowance.**

### Status

The proposal has been submitted and is currently under CEO review. Implementation is subject to approval.
